# Объединение арен utils и adaptive

В utils остаётся одна реализация аллокатора — `utils.Arena`.
Пакет `utils/arena` содержит алиасы типов и конструкторы для режима NonMoving.
Adaptive использует этот пакет напрямую; внутренний аллокатор и его копии тестов
перенесены в utils.

Исходные версии для сопоставления: utils `e3ac1ed35203` и adaptive
`e91e7d889988`. Исторические реализации нужны только для воспроизводимого
бенчмарка: скрипт извлекает их во временный каталог через git show.

## Выбор режима и быстрые операции

| Свойство | Исходная utils | Исходная adaptive | Общая utils по умолчанию | Общая NonMoving |
|---|---|---|---|---|
| Малые классы | 9 | 18 всего | Те же 9 | 18 всего |
| Payload 8192 байта | Блок 8208, без класса | Класс 8256 | Блок 8208, без класса | Класс 8256 |
| Полностью пустой регион | Только madvise, курсор не возвращается | Повторное использование | Повторное использование и madvise | Повторное использование, Trim отдельно |
| Разреженный живой регион | Подсказка эвакуации | Списки остаются доступны | Подсказка эвакуации | Списки остаются доступны |
| Поиск свободного класса | Обратный проход по регионам | Битовая карта | Прежний быстрый проход | Прямой доступ к последнему региону, затем карта |
| Незанятый TLAB при OOM/Close | Не возвращается | Возвращается | Возвращается | Возвращается |
| Stats / Trim / zeroed / capacity | Нет | Есть | Есть | Есть |

Сохранены inlineable `utils.GetSizeClass` с исходными девятью классами и
непроверяемый `GetPtr`. Расширенные классы включаются только в NonMoving.
Проверяемые операции доступны явно: `CheckedPtr` и `PayloadCapacity`.
Подсчёт свободных блоков выполняется в Stats, а не на каждом Alloc/Free.
Stats обходит цепочки под блокировками; это диагностика вне пути запроса.

Резервирование новых порций и повторное использование регионов синхронизированы
общим медленным мьютексом. Повторное выделение малого блока и обычный Free
его не берут, пока регион не опустеет. Новая anonymous mmap не обходит всю
таблицу метаданных: нулевые страницы ОС остаются ленивыми.

## Совместимость

**Формат mmap-файлов исходной utils меняется.** Старый заголовок и таблица
регионов отвергаются; такую арену следует пересоздать из данных приложения.
Исходный конструктор Go сохраняется. Это изменение формата, а не автоматическая
миграция содержимого.

NonMoving открывает файлы прежнего adaptive после штатного Close, сохраняя
смещения объектов. Обратный переход к старому аллокатору не поддерживается.
Режим и размер mapping должны совпадать при повторном открытии.

В NonMoving нет перемещения живых объектов. Default также ничего не перемещает
самостоятельно: NeedsEvacuation служит подсказкой внешнему владельцу.
Free требует отсутствия читателей; Close — завершения всех пользователей.
Формат mmap не является протоколом восстановления графа приложения после сбоя.

## Проверки

Общие тесты покрывают прежние контракты utils, оба режима освобождения, точные
блоки и классы, длительный оборот сверх ёмкости mapping, учёт claims, активные и
потерянные из sync.Pool TLAB, конкурентные Trim/Stats/Alloc/Free, смещения выше
4 GiB, метаданные в нескольких регионах и несовместимые файлы.

Проверенная рабочая версия прошла functional, race, checkptr, vet и ownership
fuzzing на native Linux amd64 и arm64. Выполнена cross-сборка для riscv64.
Интеграционные проверки adaptive и окончательные численные замеры публикуются
в следующем разделе после завершения сравнительного прогона.
